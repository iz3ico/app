## ゲームを追加するとき
1. `新しいフォルダ/index.html` を置く
2. `assets/<id>.jpg` にサムネイル（960×540）を置く
3. `top_template.html` の `GAMES` に 1 行追加
4. `python3 tools/build_top.py` でトップを作り直す
5. 必要なら `tools/make_qr.py` に追加して QR を作り直す
