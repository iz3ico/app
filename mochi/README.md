# もちもちキャラ

手描きのおもちキャラを 3D にしたページ。`index.html` をブラウザで開くと動きます（three.js を CDN から読むのでネット接続が必要）。

## キャラ

| なまえ | すがた |
|---|---|
| ぬおん | 閉じ目と ω 口のねこ。おなかに肉球 |
| んちょめちょぽ | 🌱 の生えた、ぺたんとしたおもち |
| よしめ | 🌱 の生えた、頭の大きい立ちすがた。手足つき |

右下のアイコンで切りかえ。

## できること

- つまんで引っ張るとのび〜る（上に引くと持ち上がる）。床や体の中にはめり込まない
- 🌱 は茎と葉のつけ根をつまんで引っ張れる。最大まで引くと茎ごと抜けて、6 秒後に生えなおす
- ジャンプ・つつく・ペン線のオン／オフ・効果音のオン／オフ
- 右上の ▶ で鑑賞モード（視点固定・「ななめ」「正面」切りかえ）
  - ぴょんぴょん移動（よしめは ぽてぽて歩く）、ゆらゆらダンス、くるりんジャンプ、とろ〜ん、びっくり、おじぎ、すやすや、きょろきょろ、うれしい、ぶるぶる、ぷんぷん、のび〜

## フォルダ

| パス | 内容 |
|---|---|
| `index.html` | 3D ページ本体 |
| `models/nchomechopo.glb` | んちょめちょぽの 3D モデル（輪郭線なし） |
| `models/nchomechopo_outline.glb` | 同じく輪郭線つき（裏返しの殻で線を出す方式。裏面を描かないソフト向け） |
| `models/nchomechopo_preview.png` | モデルの確認画像 |
| `tools/export_mebae.py` | んちょめちょぽを .glb に書き出す（`python3 export_mebae.py 出力.glb 出力_outline.glb`、numpy が必要） |
| `tools/preview_glb.py` | .glb を読み直して確認画像を描く（numpy・Pillow が必要） |
| `originals/` | 元の手描きイラスト |

モデルの大きさは高さ約 2.3・横幅約 3.1、原点は床の真ん中。動きや表情差分（閉じ目・笑い口・眉間のシワ）は入っていません。
